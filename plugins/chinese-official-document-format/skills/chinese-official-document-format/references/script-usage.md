# 便携脚本使用边界

`scripts/format_docx.py` 只依赖 Python 3.8+ 标准库（JSON、ZIP、XML）。无需安装 `python-docx`。仅支持新建日常公文，不修改已有 Word 文档。

```sh
python3 scripts/format_docx.py --help
python3 scripts/format_docx.py create examples/daily-document.json /tmp/document.docx --report /tmp/document-check.json
python3 scripts/format_docx.py check /tmp/document.docx --report /tmp/document-check.json
python3 scripts/format_docx.py check /tmp/document.docx --anonymous-metadata
python3 scripts/test_format_docx.py
```

完整输入字段见 `../examples/input-schema.md`。`role` 必须显式标明，脚本不会根据文字猜测标题层级。`text` 必须是字符串，保留内容、手工编号、标点、换行与制表符。Word 自动编号禁用。

页面采用 A4 纵向作为实现默认；源附件没有明确写出纸张尺寸。四侧页边距为上3.7、下3.3、左2.8、右2.6厘米。文档网格根据三号16磅基准、A4版心计算：每行28字符、每页22行。网格行间隔约29.25磅，文字段落以固定29磅行距为优先，关闭网格对齐；主标题为固定32磅。源附件只给出行距数值，“固定行距”属于此脚本明确选择的实现方式。

主送机关按附件要求两端对齐、无首行缩进；下空行与正文保持29磅行高。附件列表通过悬挂缩进对齐，附件项与前文设置保持同页链；署名在正文下留四行距离，与日期设置保持同页。署名与日期的水平中心对齐使用字符宽度估算，仍需视觉检查。不得声称仅凭 OOXML 已确保附件列表、署名和日期没有独立成页。

表格小四/五号宋体、14–18磅固定行距、居中，自适应宽度且不设置固定行高；表头重复。表格上下各空半行。脚本不会确认实际跨页效果。

红头文件首页上边距7.2厘米、会议纪要首页5厘米而其他页3.7厘米的设置，以及偶数页版记，涉及真实分页和原生模板。脚本拒绝这些模式，不用空行或段前距离冒充首页页边距。对外函件使用当次用户提供或认可的原生模板；本次模板中的实际单位信息可以保留，不写入公开技能包。

普通格式检查遇到作者、单位元数据、批注和修订时只提示，不据此改写或删除内容。仅在用户要求匿名副本时使用 `--anonymous-metadata` 将这些项目列为错误；此参数不会删除元数据，也不能检查正文语义脱敏。新建脚本不覆盖已存在的输出文件，应选择新文件名。

`check` 仅适用于由本脚本生成或已经显式标注 `Official_*` 语义样式的文档。不认识的文本段落会导致未通过，以免把无法识别的已有文档误判为合规。检查包括页边距、A4默认、文档网格、字体/字号/加粗、行距、缩进、标题行重复、手工编号要求以及作者/单位等元数据；它不能识别正文中的单位名称或个人信息。

返回值：0表示结构检查通过，1表示结构检查未通过，2表示参数或输入错误。JSON报告的 `validation` 明确注明未完成视觉或分页校验。正式交付仍需调用 Documents 工作流生成PDF/页面图片并逐页检查；若运行环境无法渲染，必须如实报告“结构检查通过，视觉校验未完成”。
